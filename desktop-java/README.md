# RustFlow JavaFX (прототип)

Java 17+, Maven 3.9+, Windows 10/11. Нужны доступ к Maven Central и рабочий JavaFX runtime. Код независим от веб-сервера; программа не отправляет телеметрию.

```sh
cd desktop-java
mvn clean package
mvn javafx:run
```

JAR в `target/` **не включает** JavaFX; для запуска вручную потребуются JavaFX SDK и `--module-path <javafx-sdk>/lib --add-modules javafx.controls`. Для распространения используйте `jpackage` с полноценным JDK и JavaFX SDK на Windows; например после установки SDK:

```powershell
jpackage --type exe --name RustFlow --input target --main-jar rustflow-desktop-0.1.0.jar --main-class app.rustflow.RustFlowApp --module-path "$env:PATH_TO_FX" --add-modules javafx.controls
```

Для EXE потребуется WiX и подходящий JDK. Проверяйте дистрибутив на чистой машине; эта команда не проверена в данном окружении.

Доступны onboarding с выбором языка, диагностические карточки CPU/RAM, графические пресеты, аккуратное обновление выбранного `client.cfg`, локальный предпросмотр цвета и карточки знаний. Укажите существующий `client.cfg`, закройте игру и подтвердите операцию: создаётся `client.cfg.bak`, затем изменяются только разрешённые графические строки; бинды, FOV, сеть, звук, лимит FPS и GC остаются без изменений. Если `.bak` уже существует, перенесите его в безопасное место перед новой операцией. Для отката закройте Rust и верните копию как `client.cfg`.

Ограничения: датчики GPU/VRAM, температуры и системного uptime пока не подключены; значения обозначены как недоступные. Настоящий Liquid Glass с преломлением фона ОС не реализован: используются полупрозрачные поверхности JavaFX. Системный твикер, очистка памяти и процессов, запись биндов, реальное применение гаммы, снимки Rust и полноценный перевод пока не реализованы. Команды и диапазоны Rust меняются, а профили не гарантируют прирост FPS; проверяйте их в F1. Windows-операции не выполняются автоматически.
