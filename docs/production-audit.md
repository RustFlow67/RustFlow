# Проверка production-сборки RustFlow

## Сборка и публикация

- Проверены `npm run lint`, `npm run typecheck`, `npm run build`, повторный typecheck после сборки и `next start` на `0.0.0.0:3000`. У экспортера исходников больше нет предупреждений о динамической трассировке файлов.
- Проверены запросы через проксированный хост, редиректы старых маршрутов, манифест и иконки, ZIP Твикера и три архива исходников. Архив сайта распаковывается обычным `unzip` без ручного изменения прав; из него прошли `npm ci`, typecheck и сборка. В отдельном запуске с `VITE_API_BASE_URL=/rustflow-backend` проверены rewrite, запросы браузера, вход/выход, чат и скачивание ZIP на том же origin.
- Основное приложение регистрирует service worker на защищённом origin при открытии сайта вне фрейма. Проверены обновление кэша, старый адрес манифеста, офлайн-открытие закэшированной страницы и исключение API из кэша, в том числе с префиксом. Установка зависит от браузера.

## Оценки и интерфейс

- Проверены 43 исходные конфигурации и их `client.cfg`, 172 сочетания с графическими режимами, 16 опорных сочетаний CPU/GPU, четыре сценария, влияние CL и частоты для DDR4/DDR5 и прогноз апгрейда. Пресеты, калькулятор и `/api/benchmark` используют одну модель. Для API проверены совместимые старые запросы, явные CL/частота, кастомные размеры и сохранение результата в PostgreSQL.
- При 1080p «Комбат» у 43 пресетов относительно Берега средний FPS и 1% low ниже на 35,9–38,6% в рейде и на 38,3–41,2% в день вайпа. Это расчёт по модели.
- Проверены BIOS-профили, авто-DDR5 на четырёх процессорах AM5, ручные частота и CL, процент герцовки и перенос этих параметров в профили, JSON и ссылки на сборку.
- Проверены переход из пресета в калькулятор и подбор Твикера из несохранённой сборки. Конфиг в просмотре Твикера и ZIP одинаково учитывает графику, ОЗУ, VRAM, лимит FPS и параметры сглаживания. Команды `lerp.*` проверены на уровне генерации файла, не в запущенной игре. Выбор рекомендуемых шагов учитывает накопитель. Неизвестные и несовместимые шаги в пакет не попадают.
- Chromium: пять основных страниц на ширинах 320–1440 px, ввод/выбор с клавиатуры и касанием, TOC при прокрутке и при переходе по хешу, раскрытие профиля, возврат фокуса из диалогов, пауза консоли и фона на скрытой вкладке, режимы reduced motion и lite. Четыре линзы фона анимируют только трансформацию, а подсветка также меняет прозрачность — без blur на линзах. Для профиля, меню и отдельных экранов также прошли проверки axe.

## Аккаунты, приватность и чат

- PostgreSQL 16: регистрация, bcrypt, перенос старого scrypt-хеша при входе, отзыв и срок действия сессий, отдельные cookie в HTTPS-iframe, сохранение сборки и восстановление в новом браузере. Убедились, что запись не проходит при смене аккаунта. Без БД, на незашифрованном origin и во фрейме без доступа к хранилищу работает локальный профиль. Такой профиль сам по себе не даёт облачных прав.
- Проверено, что гостевые действия открывают вход, а запрос ZIP к API без облачной сессии получает 401. В обоих типах профиля доступны сохранение и резервные копии; архивы Твикера собираются на сервере для облачного профиля и в браузере для локального. Проверены распаковка, права каталогов и совпадение файлов для одинаковых параметров.
- Google проверен с тестовым провайдером: выбор аккаунта, state, PKCE, подпись и claims ID-токена, повторный вход по `sub`, принятие аватара Google и отказ для постороннего URL. Для реального подключения нужны `VITE_GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` и зарегистрированный callback.
- `/api/assistant` читает `RUSTFLOW_LLM_API_KEY` только на сервере и передаёт его только настроенному провайдеру. Перенаправления при таком запросе запрещены. С тестовым провайдером проверены поток, ошибки, ограничения 5 с / 5 в час / 12 в сутки, 400 символов, модель `gpt-4o-mini` и бюджеты 450/1500 токенов. `/admin` и `/logout` не попадают в историю или запрос к модели; проверены отдельная HttpOnly-сессия и блокировка после пяти ошибок.
- Тестовые секреты не найдены в HTTP-ответах, клиентских чанках или выгрузках. Рабочий `.env` исключён из Git, исходных ZIP и трассировочных манифестов; в `.env.example` поля секретов пустые. В превью реальные ключи Google, ассистента и ADMIN не заданы.

## Перед публикацией

Задавайте реальные ключи в серверном окружении при запуске. Прокси должен перезаписывать `X-Forwarded-For`, `X-Forwarded-Host` и `X-Forwarded-Proto`, а также пропускать поток чата без буферизации. Встроенные лимиты действуют в одном процессе. Для публичного сервиса задайте общий лимит запросов на прокси и бюджет у провайдера. Для обновляемой базы сделайте резервную копию и примените `npm run db:push`.

Реальные Google/OpenAI, Docker-образ, установка PWA на физическое устройство и нативный установщик не проверялись. App Kit остаётся набором шаблонов. FPS в калькуляторе — прогноз, а 144+ FPS для эффектов интерфейса — цель, не результат замера на устройстве.
